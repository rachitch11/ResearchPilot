PORTABILITY, ACCOUNT INDEPENDENCE & CONTINUATION REQUIREMENTS
ResearchPilot MUST be designed so development can continue if the current Replit account runs out of Agent credits, reaches usage limits, or becomes unavailable.
The Replit account MUST NOT be treated as the source of truth for the project.
1. Source of Truth
The complete project source code must exist in the repository and must be runnable independently of Replit Agent.
Do not keep critical architecture, implementation details, configuration, TODOs, or project state only inside the Replit Agent conversation.
The GitHub repository must contain everything required to understand, run, test, and continue the project.
2. GitHub Portability
Configure the project so it can be pushed to GitHub and later imported/cloned into:
    • another Replit account
    • another Replit workspace
    • a local development machine
    • another compatible hosting platform
Do not introduce unnecessary Replit-specific dependencies.
3. Environment Variables and Secrets
All credentials and environment-specific configuration MUST use environment variables.
At minimum support:
    • GEMINI_API_KEY

    • ADMIN credentials/configuration

Never hard-code API keys, passwords, tokens, or secrets.
Create and maintain:
.env.example
The .env.example file must contain variable names, safe placeholder values, and comments explaining where each value comes from.
Never commit real secrets to GitHub.
